# ZeroOne Ops

Review changes. Remediate findings. Stay in control.
{ .zeroone-lead }

Governed OpenAI-assisted engineering workflows, operated through GitHub or
GitLab issues and pull/merge requests.

ZeroOne Ops reviews changes, collects normalized scanner findings, and prepares
bounded remediation requests. Operators control policy and recovery; validation,
review, and provider-native lifecycle evidence remain visible alongside the work.
